# Chronicle

Short notes on what we shipped and why.

The Chronicle is the human-facing side of Star releases. Each release gets a dated entry; not every release is worth a paragraph, but the ones that change how Star runs should be written down somewhere other than a GitHub release body.

## About

This is not a changelog in the traditional sense. It's a chronicle: dated, in product voice, and kept around because it has to be written once and read many times. Release notes in GitHub Releases still carry the full diff; the Chronicle is what we expect people to actually read.
