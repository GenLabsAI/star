Use the `search_history` tool to search your conversation history across past sessions.

Use this tool when:
- The user references a past conversation ("remember when we...").
- The user asks you to recall previous decisions, context, code patterns, or solutions.
- You are resuming work that spans multiple sessions and need context about what was discussed before.
- You suspect you have solved a similar problem in this project before and want to find the solution.

The tool returns snippets of matching messages along with their originating Session ID and Role. If a result looks relevant but you need the full context, you can use the Session ID to read the rest of the conversation.

Be specific with your query keywords. Think about the exact words, function names, or error messages that might have appeared in the past discussion.
