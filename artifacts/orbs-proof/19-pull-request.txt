## A branch that is not on the remote

$ star pr --title "chore: unsent branch"

## What the command asks GitHub

$ PATH=<recording gh>:$PATH star pr --push --title "chore: stubbed pull request" --body "Recorded, not sent."
Pull request #4242
  title             chore: stubbed pull request
  branch            proof/pr-stub -> main
  repository        GenLabsAI/star (origin)
  url               https://github.com/GenLabsAI/star/pull/4242
  pushed            proof/pr-stub to origin
exit=0

$ cat <outdir>/pr-gh-stub-args.txt      # the exact gh invocation, one line of arguments
pr create --repo GenLabsAI/star --head proof/pr-stub --base main --title chore: stubbed pull request --body Recorded, not sent.

the branch really is on the remote now:
refs/heads/proof/pr-stub

## Against the real GitHub CLI

$ star pr --push --title "chore: exercise the pull-request command"
          
   ERROR  
          
  Failed to open the pull request: exit status 1: pull request create failed: GraphQL: Resource not accessible by     
  personal access token (createPullRequest).                                                                          
exit=1

# GitHub refused the create call with the credential this machine has;
# the attempt above is the real API answer, not a local check.
